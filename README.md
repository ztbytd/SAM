# 股骨头坏死灰度分析系统 (Femoral Head Necrosis Analysis System)

## 📋 项目背景

这是一个用于股骨头坏死（Femoral Head Necrosis）医学影像分析的桌面应用。通过图像处理和计算机视觉技术，自动识别股骨头区域，计算硬化带内外的灰度比值，辅助临床诊断。

## ✨ 核心功能

### 1. 图片管理
- **单张导入** - 选择单张医学影像进行分析
- **批量导入** - 一次导入多张图片，自动创建项目文件夹
- **快速切换** - 缩略图列表，点击快速切换图片
- **项目统计** - 实时显示总数、已分析、已保存数量

### 2. 股骨头检测
- **自动检测** - 使用图像处理算法自动识别股骨头位置
- **手动调整** - 支持手动微调检测结果
- **圆形标记** - 绘制股骨头外圆和内圆（r-6mm）

### 3. 灰度分析
- **硬化带识别** - 自动检测硬化带交点
- **灰度比值计算** - 计算硬化带内外的灰度比值
- **多点分析** - 支持多个测量点的数据记录

### 4. 校准方式
- **DICOM 校准** - 从 DICOM 文件自动读取像素/毫米比例
- **手动输入** - 手动输入 px/mm 比例
- **默认校准** - 使用默认校准参数

### 5. 结果保存
- **单张保存** - 保存当前图片的分析结果
- **批量保存** - 一键保存所有已分析的图片
- **自动输出** - 自动创建项目输出文件夹，按时间戳命名

### 6. 报告导出
- **Excel 导出** - 生成专业格式的 Excel 报告
- **格式化表格** - 包含文件名、分析状态、灰度比值等信息
- **统计汇总** - 自动计算平均值和统计数据

### 7. 用户界面
- **深色主题** - 专业的深色界面，减少眼睛疲劳
- **实时预览** - 图片缩放、拖动、旋转功能
- **状态指示** - 清晰的分析状态和保存状态指示

## 🚀 快速开始

### 系统要求
- Python 3.7+
- Windows 10/11 (或 Linux/Mac)
- 4GB RAM (推荐 8GB)
- 100MB 磁盘空间

### 安装步骤

**1. 安装依赖库**
```bash
pip install -r requirements.txt
```

**2. 运行应用**
```bash
python femoral_gui.py
```

### 基本使用流程

```
1. 点击"批量导入" → 选择多张图片
   ↓
2. 系统自动创建输出文件夹 (output_YYYYMMDD_HHMMSS)
   ↓
3. 对每张图片点击"自动分析"
   ↓
4. 查看分析结果，可手动调整
   ↓
5. 点击"保存"保存单张结果
   ↓
6. 点击"批量保存"保存所有结果
   ↓
7. 点击"导出Excel"生成报告
```

## 🔍 常见问题

### Q: 如何处理中文路径的图片？
A: 应用已优化处理中文路径，使用 `np.fromfile + cv2.imdecode` 方式读取图片。

### Q: 支持哪些图片格式？
A: 支持 OpenCV 支持的所有格式：JPG、PNG、BMP、TIFF 等。

### Q: 如何导出 Excel 报告？
A: 分析完成后，点击"导出 Excel"按钮，选择保存位置即可。

### Q: 可以打包成 EXE 吗？
A: 可以，使用 `pyinstaller --onefile --windowed femoral_gui.py` 命令打包。

### Q: 支持 DICOM 格式吗？
A: 支持，可以从 DICOM 文件读取校准参数。
